# Calendário Weatherlight

Página de eventos semanais da Weatherlight Games & Collectibles (Évora).
Publicada com GitHub Pages; atualizada semanalmente a partir das stories e do texto da semana.

- `index.html` — a página publicada
- `img/` — miniaturas dos eventos
- `gerador/` — modelo, textos dos eventos e script que gera a página
